# Jinwoo Oh

Computer Science student at Northwestern University graduating in 2027 with a minor in Machine Learning and Data Science.

## Selected work

- [EvalGate](https://github.com/starJin2003/EvalGate). Regression gate for LLM apps on Kubernetes that blocks a pull request when model behavior regresses.
- [PromptFighter](https://github.com/starJin2003/PromptFighter). Real-time multiplayer prompt battle game judged by Claude, built at WildHacks 2026. Live at [promptfighter.space](https://promptfighter.space).
- [Stepping Stones](https://github.com/starJin2003/stepping-stones). Offline multilingual AI that traces tourists' SMS referrals for a Kenyan coffee farm on a phone. [Live demo](https://stepping-stones-plum.vercel.app).
- [PharmAgent](https://github.com/starJin2003/pharmagent). Drug interaction Q&A agent that cites an FDA label for every answer. [Demo](https://huggingface.co/spaces/starJin2003/pharmagent).
- [coAuthor](https://github.com/davidyim03/coAuthor). Serverless storytelling app on AWS where AI illustrates each sentence of a shared story.
- [codenames-LLM-study](https://github.com/starJin2003/codenames-LLM-study). Study of whether LLM agents invent secret signals to cheat at Codenames.
