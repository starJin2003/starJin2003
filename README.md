## Selected work

- [EvalGate](https://github.com/starJin2003/EvalGate). Regression gate for LLM apps on Kubernetes that tests every pull request against an approved baseline of 97 eval cases and blocks the merge when model behavior regresses. Ingests production traces through Kafka at 4,001 traces per second and turns failures into new eval cases.
- [PromptFighter](https://github.com/starJin2003/PromptFighter). Real-time multiplayer battle game where players fight by writing prompts for their characters and Claude judges every fight through structured outputs. Built at WildHacks 2026 with Next.js and Supabase Realtime. Live at [promptfighter.space](https://promptfighter.space).
- [Stepping Stones](https://github.com/starJin2003/stepping-stones). Offline multilingual AI app that traces word-of-mouth referrals from tourists' SMS for a Kenyan coffee farm. Runs a quantized multilingual model on a Galaxy S22 with Transformers.js and ONNX Runtime and raised top-1 referral matching from 13/22 to 20/22. Built solo for the Hack-Nation x World Bank Small AI for Development hackathon. [Live demo](https://stepping-stones-plum.vercel.app).
- [PharmAgent](https://github.com/starJin2003/pharmagent). Drug interaction Q&A agent that answers from 500 FDA drug labels and cites a label section for every answer. Hybrid FAISS and BM25 retrieval on LangGraph with Recall@5 at 0.95 and citation accuracy at 0.96. [Demo on Hugging Face Spaces](https://huggingface.co/spaces/starJin2003/pharmagent).
- [coAuthor](https://github.com/davidyim03/coAuthor). Serverless storytelling app where several people write a story together one sentence at a time and AI illustrates each sentence. Built on AWS Lambda, API Gateway WebSockets, and DynamoDB, with an asynchronous illustration pipeline that cut the storybook wait from 7 minutes to 20 seconds.
- [codenames-LLM-study](https://github.com/starJin2003/codenames-LLM-study). Study of whether LLM agents invent secret signals to cheat at Codenames. Ran 51 self-play games with GPT-5.5 and Llama-3.3-70B across 4 conditions and found zero covert signals in 293 clues.
